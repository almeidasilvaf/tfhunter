# Domain annotation for the algae species Galdieria sulphuraria The data set was created using the function `annotate_domains()`.

Domain annotation for the algae species Galdieria sulphuraria

The data set was created using the function
[`annotate_domains()`](annotate_domains.md).

## Usage

``` r
data(gsu_annotation)
```

## Format

A list of 4 data frames (**PlantTFDB**, **TAPscan**, **CISBP**, and
**TFClass**) with domain annotation, as returned by
[`annotate_domains()`](annotate_domains.md).

## Examples

``` r
data(gsu_annotation)
```

# Package index

## All functions

- [`annotate_domains()`](annotate_domains.md) : Annotate protein
  sequences with domains used for TF classification

- [`cisbp_scheme`](cisbp_scheme.md) : Data frame of CIS-BP's TF family
  classification scheme

- [`classify_tfs()`](classify_tfs.md) : Identify TFs and classify them
  in families

- [`get_tf_counts()`](get_tf_counts.md) :

  Get TF frequencies for each species as a `SummarizedExperiment` object

- [`gsu`](gsu.md) : Protein sequences of the algae species Galdieria
  sulphuraria

- [`gsu_annotation`](gsu_annotation.md) :

  Domain annotation for the algae species Galdieria sulphuraria The data
  set was created using the function
  [`annotate_domains()`](../reference/annotate_domains.md).

- [`hmmer_is_installed()`](hmmer_is_installed.md) : Check if HMMER is
  installed

- [`list_schemes()`](list_schemes.md) : List available TF classification
  schemes

- [`planttfclass_scheme`](planttfclass_scheme.md) : Correspondence table
  between TAPscan and Plant-TFClass

- [`planttfdb_scheme`](planttfdb_scheme.md) : Data frame of PlantTFDB's
  TF family classification scheme

- [`tap_class`](tap_class.md) : Classes of transcription-associated
  proteins (TAPs) in TAPscan

- [`tapscan_scheme`](tapscan_scheme.md) : Data frame of TAPscan's
  classification scheme

- [`tfclass_scheme`](tfclass_scheme.md) : Correspondence table between
  CIS-BP and TFClass
